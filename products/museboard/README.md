# Museboard

- Import PNG, JPEG, and WebP images or index local folders.
- Organize references in catalogs and arrange them on boards.
- Link artwork to references and create palettes with PNG, GPL, and ACO export.
- Discover images with your own Brave or SerpApi keys and save selected images when you have the applicable rights.
- Export boards as PNG and run timed practice sessions.
- Capture video frames and prepare PNG exports from supported images or saved flattened Krita canvases.
- Use explicit, on-demand image tagging with a user-configured local or private LAN vision server.
