# Changelog

## 1.6.0

- Pair a browser on a trusted LAN to browse and search the library, view saved boards, copy images, upload references or drawings, and arrange images on temporary boards.
- Link a second Museboard desktop app to the owner's LAN library for shared images, organization, and saved-board edits. Shared changes are stored on the host; temporary boards remain on the device where they are created.
- Edit tags on individual images or selections with a searchable picker and explicit tag creation. Library thumbnails now show drawing/reference link badges.
- Save library views and thumbnail sizes, restore browsing position, and move between images across gallery pages. Skip individual images while reviewing an import batch.
- Revisit video sources using titled history entries and remove unwanted entries.
- Honor folder and catalog destinations when importing dropped images, and remember the last selected import type.
- Use clearer red X icons for removal controls.

## 1.4.0

- Open up to five independent floating boards, create empty temporary boards, and restore saved and temporary board window geometry.
- Add gallery images to boards with placement badges and repeated additions, and adjust board zoom with a percentage slider.
- Browse linked images as text links with hover and focus previews, and navigate back through image details more reliably.
- Copy multiple images or drawings with their references, copy drawings without references, and continue batch operations past unavailable images.
- Drag and drop multiple images between catalogs, watched folders, and the managed library, transferring catalog membership or safely moving files.
- Add, tag, change the type of, or delete multiple selected images; explicitly save image imports with editable titles, types, and rotation.
- Open images on temporary boards and save Instagram compositions to the library.
- Remove images from catalogs with simpler catalog controls.
- Generate tags from image details, with improved tagging context, startup feedback, grid refresh, toolbar actions, and icons.

## 1.0.0

- Search Brave Images and Google Images through SerpApi with your own provider keys, and save selected images when you have the applicable rights.
- Use explicit, on-demand AI tagging with a user-configured localhost or private LAN vision server.
- Export boards as PNG with placement effects, background options, and a preview.
- Run timed practice sessions inline or in a floating window, with session controls and a completion summary.
- Navigate image-detail history and find related library images by shared tags.
- Pick custom palette colors, capture video frames, and copy library images to the clipboard.
- Customize catalog and folder icons and colors, and import backups with conflict review.

## 0.1.0

- Organize local and explicitly saved references into catalogs and persistent boards.
- Link artwork to its references and generate deterministic color palettes.
- Discover images using a user-provided Brave Search API key and applicable storage rights.
- Copy a transparent palette image or export PNG, GPL, and ACO files.
- Prepare Instagram PNG exports from supported images and saved flattened Krita canvases.
