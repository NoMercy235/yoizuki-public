# Third-party notices

Museboard 1.4.0 includes Electron and Chromium, Angular, RxJS, Konva, better-sqlite3/SQLite, sharp/libvips, and their dependencies. The application also adapts the author's Palette Companion color-extraction code.

The packaged application contains Electron's license as `build/legal/ELECTRON-LICENSE.txt`, Chromium notices as `build/legal/LICENSES.chromium.html`, installed production dependency metadata and available license/notice texts as `build/legal/THIRD-PARTY-NOTICES.txt`, and Angular's extracted bundle licenses as `build/renderer/3rdpartylicenses.txt`. The libvips package's own dependency, source, and license listing is included with the production dependency notices; the relevant GNU LGPL and GPL texts are in `build/legal/`. Review these files and the bundled native libraries for the exact release before distribution.
