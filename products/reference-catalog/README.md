# Yoizuki Reference Catalog

Floating reference-image boards that belong to a Krita document. Arrange several
images together, keep boards visible while browsing for references, and save the
images and layout inside your painting's `.kra` file.

## Compatibility

Targets Krita 5.2+ with Python 3, PyQt5, and Qt 5.14+. User testing has covered
macOS with Steam Krita 5.3.3, including Brave/Pinterest closeup-image drops.
Windows, Linux, and other Krita builds have not been tested natively. Not all
native acceptance checks have been completed; the source ZIP includes the
detailed testing record and checklist.

No third-party Python packages or background service are needed inside Krita.

## Install or update

1. Download the installable plugin ZIP above.
2. In Krita, choose **Tools → Scripts → Import Python Plugin…** and select it.
3. Enable the plugin when prompted, then restart Krita. If necessary, enable
   **Yoizuki Reference Catalog** in **Preferences / Settings → Configure Krita →
   Python Plugin Manager** and restart again.

Import the new ZIP and restart to update. To disable the plugin, uncheck it in
Python Plugin Manager and restart; this does not delete references from `.kra`
files. Keep backups of artwork, especially when trying a new plugin version.

## Use

Open a document, then choose **Tools → Scripts → Yoizuki Reference Catalog →
Boards → New Reference Board**. Create multiple boards as needed.

- Add files, paste images, or drag supported browser images onto a board.
- Select and drag images to arrange them. Resize with corner handles, rotate
  with the circular handle, and use the toolbar for flips, ordering, locking,
  duplication, deletion, and reference undo/redo.
- Drag a board's title to move it and double-click to rename it. Minus hides
  the board; × removes it. Reference Undo can restore a removed board.
- Auto-hide is off by default, allowing you to switch to your browser and drag
  references onto a visible board. Toggle the eye button to change this per board.
- Hover over toolbar icons for about two seconds to see their commands.
- Alt/Option-click samples an image's source pixel into Krita's foreground color.
- Save as **`.kra`** to keep embedded images and board settings with the painting.
  PNG/JPEG and other export formats do not preserve boards. References follow
  the active document, and reference undo does not invoke painting undo.

## Limits and troubleshooting

Common raster formats are supported; animated GIFs use their first frame.
Images are limited to 64 MiB / 80 megapixels, and network imports time out after
20 seconds. Pinterest imports use the supplied preview image, not a guessed
higher-resolution original. Authenticated images and unsupported browser drag
formats may fail; save the image locally or use Copy Image / Paste in that case.
Imports do not use browser cookies or credentials.

For drag problems, try the drop once, then choose **Tools → Scripts → Yoizuki
Reference Catalog → Troubleshooting → Copy Drag-and-Drop Diagnostics**. The
report includes the plugin/runtime versions, widget state, and MIME format names,
but no image data, URLs, file paths, or credentials. Include it when
[reporting a problem](https://github.com/NoMercy235/yoizuki-public/issues/new).
