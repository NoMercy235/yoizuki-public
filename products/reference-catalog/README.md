# Yoizuki Reference Catalog

- Create floating reference-image boards saved inside Krita documents.
- Import images from files, the clipboard, public image URLs, and supported browser drags.
- Arrange, resize, rotate, flip, lock, duplicate, and reorder references; sample colors and undo reference changes.
- Zoom boards independently of their references, and extract colors as GPL palettes or sRGB paint layers.
- Keep board settings and embedded images with the painting in `.kra` files.
