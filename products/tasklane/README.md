# Tasklane

Tasklane is a focused macOS menu-bar Kanban board for daily and weekly work. It
keeps a small set of tasks in To Do, In Progress, and Done columns, with quick
creation, drag-and-drop ordering, recurring tasks, due dates, priorities, tags,
notes, and muted card colors.

## Compatibility

Tasklane requires macOS 14 Sonoma or later. The application archive contains a
universal binary for Apple silicon and Intel Macs.

## Install with Homebrew

Homebrew 7 and later require an explicit one-time trust step for third-party
casks:

```sh
brew trust --cask nomercy235/yoizuki-public/tasklane
brew tap NoMercy235/yoizuki-public https://github.com/NoMercy235/yoizuki-public.git
brew install --cask nomercy235/yoizuki-public/tasklane
```

Upgrade after a new release with:

```sh
brew update
brew upgrade --cask tasklane
```

Uninstall with:

```sh
brew uninstall --cask tasklane
```

## Gatekeeper

Tasklane is ad-hoc signed rather than Developer ID signed or notarized. On the
first launch after installation or an upgrade, try opening Tasklane once. If
macOS blocks it, open **System Settings → Privacy & Security** and choose
**Open Anyway** for Tasklane.

This keeps Gatekeeper enabled. Do not remove quarantine recursively from the app.

## Data and source

Task data is stored locally on the Mac. Cloud synchronization is not included in
version 1.0.0. Development history is maintained in a separate private
repository and is not part of the autogenerated source archives on this release.
