# Yoizuki Public

Public downloads, documentation, licenses, and release notes for Yoizuki projects.
Development repositories and their Git histories are managed separately.

## Projects

- **[Yoizuki Reference Catalog](products/reference-catalog/README.md)** — floating
  reference boards saved inside Krita documents.
  [Download version 1.1.0](https://github.com/NoMercy235/yoizuki-public/releases/tag/reference-catalog-v1.1.0).
- **[Tasklane](products/tasklane/README.md)** — a focused macOS menu-bar Kanban
  board for daily and weekly tasks.
  [Download version 2.0.0](https://github.com/NoMercy235/yoizuki-public/releases/tag/tasklane-v2.0.0).

## Downloads and support

Use the named installation assets attached to [Releases](https://github.com/NoMercy235/yoizuki-public/releases).
GitHub's autogenerated **Source code (zip)** and **Source code (tar.gz)** contain
this documentation repository, not an installable product. When a product has a
separate source archive, download that explicitly named asset instead.

For a bug report, [open an issue](https://github.com/NoMercy235/yoizuki-public/issues/new)
with the product name, version, operating system, and steps to reproduce it.
Do not include credentials, private artwork, or personal data.
